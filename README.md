# Pesquisa de Satisfação Cardios — protótipo

Protótipo navegável e testável da nova pesquisa de satisfação de clientes da Cardios.
Fluxo curto (3 perguntas), com ramificação por nota NPS, comentário único, contato
opcional com fechamento de loop, e um "Modo de teste" no rodapé para simular
qualquer caminho sem dados reais (não aparece em produção).

Material do departamento de Marketing da Cardios (responsável: Flávia Torretta) —
Claude auxiliou na estruturação e prototipagem a partir da planilha da pesquisa
anterior (FRM 08-004, ano-base ABR24-MAR25).

Para publicar via GitHub Pages: Settings → Pages → Deploy from branch → `main` / `/ (root)`.
